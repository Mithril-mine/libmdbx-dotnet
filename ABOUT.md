# Паспорт проекта mdbx.NET

## Обзор проекта
- **Название**: mdbx.NET
- **Описание**: .NET привязки (dotnet) к [libmdbx](https://libmdbx.dqdkfa.ru/), преемнику LMDB (Lightning Memory-Mapped Database)
- **Репозиторий**: libmdbx-dotnet
- **Основной язык**: C#
- **Фреймворк**: .NET
- **Лицензия**: Apache License, Version 2.0

## Структура проекта
```
libmdbx-dotnet/
├── MDBX/                     # Основная библиотека привязок
│   ├── Interop/              # Определения P/Invoke для нативной libmdbx
│   ├── MdbxEnvironment.cs    # Управление окружением
│   ├── MdbxTransaction.cs    # Обработка транзакций
│   ├── MdbxDatabase.cs       # Операции с базами данных
│   ├── MdbxCursor.cs         # Операции с курсорами
│   └── *.cs                  # Различные поддерживающие классы
├── MDBX.UnitTest/            # Юнит-тесты для привязок
├── native/                   # Нативные бинарники libmdbx для разных платформ
│   ├── windows/
│   └── linux/
├── README.md                 # Обзор проекта и примеры использования
├── ISSUES.md                 # Известные проблемы и уязвимости
├── ABOUT.md                  # Этот файл - паспорт проекта
└── libmdbx-dotnet.sln        # Файл решения Visual Studio
```

## Ключевые особенности
- Предоставляет .NET интерфейс к встраиваемой базе данных libmdbx
- Поддерживает Windows и Linux платформы
- Поддержка множества архитектур (x86, x64, ARM, ARM64)
- Полная поддержка ACID-транзакций
- Поддержка множества баз данных в одном окружении
- Возможность итерации с помощью курсоров
- Поддержка пользовательских сериализаторов для типов ключ/значение

## Текущее состояние
- **Версия**: Based on libmdbx bindings
- **Стабильность**: Функциональна с известными проблемами, документированными в ISSUES.md
- **Документация**: README.md содержит примеры использования
- **Тестирование**: Юнит-тесты доступны в проекте MDBX.UnitTest

## Зависимости
- **Нативная**: библиотека libmdbx (не включена в NuGet пакет, должна предоставляться отдельно)
- **.NET**: Совместима с .NET Standard 2.0 и выше
- **Платформа**: Windows, Linux

## Информация о сборке
- **Файл решения**: libmdbx-dotnet.sln
- **Основной проект**: MDBX.csproj
- **Тестовый проект**: MDBX.UnitTest.csproj
- **Инструмент сборки**: MSBuild (Visual Studio или dotnet CLI)
- **Конфигурации сборки**: Debug, Release
- **Платформы сборки**: x86, x64, ARM, ARM64

## Правила тестирования
- Юнит-тесты расположены в проекте MDBX.UnitTest
- Для запуска тестов использовать: `dotnet test` или через Test Explorer в Visual Studio
- Тесты должны покрывать основные функции библиотеки: управление окружением, транзакции, операции с БД, курсоры
- Перед коммитом необходимо убедиться, что все тесты проходят успешно
- Тестирование производится на поддерживаемых платформах (Windows, Linux)
